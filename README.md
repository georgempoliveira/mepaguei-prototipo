# Me Paguei — Protótipo navegável

Protótipo clicável do app **Me Paguei** (+ app parceiro **BlueHub**) para testes de usabilidade.
Nenhum dado digitado é salvo — recarregar a página zera tudo.

**Acesse:** https://georgempoliveira.github.io/mepaguei-prototipo/

- No desktop, o painel ao lado do celular permite pular direto para qualquer fluxo.
- No celular, toque três vezes na barra de status para abrir esse painel.
